# 📊 Olist E-Commerce Executive Dashboard (Power BI)

## 🌟 Overview
An executive-level Power BI dashboard built using the comprehensive **Olist E-Commerce dataset**. This project transforms raw transactional data into actionable business insights, focusing on revenue trends, payment methods, customer distribution across states, and installment behaviors.

---

## 🛠️ Key Features & Visualizations
* **Executive KPIs:** Real-time tracking of **Total Revenue** and **Total Orders** with dynamic date filtering.
* **Interactive Date Slicer:** Custom-styled date slider for seamless temporal analysis.
* **Revenue by Payment Methods:** Breakdown of transaction volumes across credit cards, boleto, vouchers, and more.
* **Payment Installments Breakdown:** Detailed analysis of customer payment installment preferences.
* **Top 10 States by Revenue (`Revenue by State`):** A clean, optimized horizontal bar chart highlighting the top-performing geographic regions using advanced DAX filtering (`Top N`).
